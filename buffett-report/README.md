# 巴菲特晨報

每日以價值投資原則（護城河、ROE、自由現金流、安全邊際、能力圈、不用槓桿）整理台股、國際新聞與美元／日圓換匯判斷。

- `index.html`：晨報網頁，讀取 `reports/` 裡的 JSON 顯示最近 30 份報告（可用 GitHub Pages 瀏覽）。
- `reports/YYYY-MM-DD.json`：每日報告原始資料。
- `reports/index.json`：報告清單（新到舊），新增報告後執行 `python3 scripts/build_index.py` 重建。

> 內容為研究筆記，不構成投資建議，也不代表巴菲特本人看法；不保證報酬或匯率方向。
